
  # Perfect Makeover — Bridal Makeup & Beauty Studio

  This is a code bundle for Perfect Makeover, a bridal makeup and beauty studio in Yamuna Nagar, Haryana. The original project is available at https://www.figma.com/design/jn84m5vDYgXMXcG64HpH65/3D-Animated-Makeup-Artist-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
